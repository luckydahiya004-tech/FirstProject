# Smart Quiz App

## Project Overview

Smart Quiz App is a Flutter application developed as a Week 01 Minor Project. The app presents multiple-choice Flutter questions, calculates the user's score, and displays the final result.

## Features

* Welcome Screen
* 10 Multiple Choice Questions
* One Question at a Time
* Score Calculation
* Progress Indicator
* Result Screen
* Restart Quiz
* Clean Material Design UI
* Responsive Layout
